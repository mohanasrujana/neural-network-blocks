# Neural Network Blocks

This repository generates a database of small neural networks that implement basic Boolean logic gates and circuit-level building blocks.

## Current Scope

This version supports basic boolean gates like:

- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

For each gate, the database stores:

1. symbolic logic name
2. truth table
3. multiple neural implementations
4. verification result
5. architecture metadata
6. weights or weight references
